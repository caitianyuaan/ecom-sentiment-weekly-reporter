## Suggested query pattern

Combine these four dimensions in web searches:
1. market term: `US`, `United States`, `UK`, `Britain`, `British`
2. platform term: `Amazon`, `Temu`, `SHEIN`, `TikTok Shop`, `eBay`, `Meta`, `Instagram`, `Walmart`, `Google`
3. event term: `fees`, `returns`, `delivery`, `policy`, `seller`, `ads`, `livestream`, `partnership`, `trust`, `payments`, `refunds`, `counterfeit`, `recommendation`
4. source term when needed: the publisher name

## Coverage heuristics

- Start from primary reporting or official statements.
- Add one secondary source only if it contributes context not present in the primary source.
- Prefer market-specific relevance over general corporate news.
- Prefer news with direct implications for product quality, seller trust, pricing, delivery, after-sales, content discovery, or shopping confidence.

## De-duplication rule

Treat the following as the same story unless materially different:
- multiple rewrites of the same press release;
- multiple summaries of the same quarterly update;
- forum reposts that add no new facts.

## Market-specific reminders

### US
- Pay extra attention to antitrust, consumer safety, seller fees, Prime / fulfillment, ad product changes, creator commerce, and cross-border marketplace competition.

### UK
- Pay extra attention to UK consumer protection, delivery standards, returns expectations, fashion / beauty retail signals, CMA / policy direction, and local assortment / fulfillment updates.
