# 新用户首次配置

目标是让用户在不了解配置文件的情况下完成设置。不要先说“找不到配置文件”，也不要一次展示 JSON 字段。

## 快速入口

首次运行时先提供两个入口：

- **使用推荐配置，立即生成**：美国 + 英国；主流电商平台；均衡来源；中文紧凑 HTML；仅保存本地。
- **自定义配置**：用下面四轮短问题完成设置。

用户回复“默认”“推荐配置”或意思相同的话时，直接从 `sample-config.template.json` 创建本地可运行配置，不再逐项追问。

## 四轮引导

每轮只问当前决策，不要求用户理解字段名。给出推荐选项，并允许自由填写。

### 第一轮：看哪里、看谁

询问：

1. 关注哪些市场？推荐美国 + 英国，也可填写其他国家或地区。
2. 关注哪些平台？可选全部主流平台，或列出具体平台。

默认平台：Amazon、Temu、SHEIN、TikTok Shop、eBay、Instagram / Meta、Walmart、Google。

### 第二轮：看什么、观察哪些指标

分别询问新闻主题和观测指标。不要把两者混成一串关键词。

观测指标提供以下分组：

- **商品与供给**：品质、正品、卖家可信度、丰富度、独特性、品牌供给。
- **内容与发现**：可购物内容、推荐相关性、内容质量、商品/品牌发现。
- **价格与促销**：价格竞争力、运费、折扣吸引力、促销规则和价格可信度。
- **购物体验**：搜索、功能易用性、评论与评分。
- **物流履约**：配送速度、包裹完好、物流追踪。
- **售后与信任**：退货退款、支付安全、客服、隐私和政策沟通。
- **经营规模与增长**：GMV、流量、订单、卖家数、活跃买家、转化与复购；仅在来源提供可靠数据时使用。

默认选择全部分组，并在每条新闻中只映射有证据支持的指标。用户可选择某些分组、点名具体指标，或要求排除指标。配置写入 `observation_metrics`。

主题可直接沿用默认，也可增删监管公告、平台卖家政策、消费者投诉、行业数据、物流、退货、价格、内容电商、广告推荐、支付安全等。

### 第三轮：从哪里看

询问来源策略：

- **均衡来源（推荐）**：官方公告、监管机构、主流媒体、行业媒体和经过核验的社区反馈。
- **官方与监管优先**：平台公告、政府与监管机构优先。
- **媒体与行业优先**：主流媒体、零售及电商行业媒体优先。
- **消费者与卖家舆情优先**：社区、论坛和投诉信号占比更高，但仍需交叉验证。
- **自定义网站**：让用户列出必须包含或排除的网站。

### 第四轮：怎么交付

先区分两个概念：

1. **文件格式**：HTML（推荐）、Markdown、HTML + Markdown。
2. **发送渠道**：仅本地、飞书群、飞书文档归档、飞书群 + 文档归档。

HTML 默认使用 `consulting_compact`、合并市场、美国在前、不使用图片。

只有用户选择飞书群时才询问 `feishu_group_id`；只有选择文档归档时才询问 `feishu_doc_url`；任一飞书渠道启用时再询问署名。不要要求仅本地用户填写飞书信息。

## 确认与保存

写配置前，用不超过 9 行的中文摘要确认：市场、平台、主题、观测指标、来源、报告语言、文件格式、发送渠道、日期默认和署名。用户已明确回答的内容不再重复询问。

将配置保存到 `~/.ecom-sentiment-weekly-reporter/config.json`。保存后立即运行预检；预检通过就继续生成，不要让用户再发送一次“运行”。

## 修改已有配置

用户说“改成只看英国”“以后发飞书”“不要 Markdown”等自然语言时，直接更新对应设置，展示简短变更摘要，然后按新配置运行。不要要求用户手动编辑 JSON。
